# OpenPages / 开页

2026-09-06 · 产品界面规范

## 品牌方向

开页是私人手帐，不是任务监控面板。视觉重心是用户写下的内容；品牌只在字标、封面和少量界面状态中出现。允许空白，不使用连续打卡、完成率或催促式文案。

采用 `brand`、`design`、`design-system` skill 的身份一致性、语义令牌和组件状态方法。`brandkit` 的整体风格检查用于控制装饰密度，不把宣传板或拼贴式品牌墙搬进编辑器。

## 标识

- 主标识：开页字标与 OpenPages 英文名。
- 图形：两张展开的纸页与朱红书签，源文件 `assets/openpages-mark.svg`。
- 界面内图形尺寸 36px，四周至少留 8px。
- 只在侧栏和浏览器图标使用主标识；内页不重复产品名。
- 新标识随项目 MIT 许可提供。没有使用 TN、Hobonichi、Goodnotes 的标识或专属图案。

## 色彩与材质

实施源：`workspace.css` 中的品牌原始值、语义角色和组件别名。

| 角色 | 色值 | 使用范围 |
| --- | --- | --- |
| 常青绿 | #355B49 | 标识、主要选中状态 |
| 朱红 | #B46C62 | 标识书签、少量仪式元素 |
| 墨色 | #303C38 | 主要文字 |
| 灰绿 | #68776F | 白底上的次级文字 |
| 雾白 | #F7F9F8 | 导航背景 |
| 本白 | #FCFDFC | 工具栏与弹层 |
| 淡苔 | #E5EEEA | 选中背景 |
| 错误 | #AD4B45 | 保存失败、破坏性状态 |

纸色、笔色、封皮色仍由用户选择，不与品牌色绑定。纸张纹理只作用于内页，导航和表单不叠加纸纤维。皮革只露出窄边，中缝只保留一处阴影。

## 字体

- 界面：系统无衬线字体，中文优先 PingFang SC / Microsoft YaHei。
- 内页标题和中文字标：系统宋体 / 明朝体回退，27px；手机 25px。
- 正文：桌面 16px、手机 15px，2 倍行高。
- 面板标题：18px；模板名：14px；工具文字：12px。
- 英文字标：Georgia；不依赖远程字体下载，离线仍可显示。
- 不使用负字距，不用视口宽度缩放字号，不人为拉伸字形。

## 信息结构

1. 侧栏负责找内容：日期、最近页、搜索与回看、设置与备份。
2. 第一行负责文档导航：日期、月/周/日、保存状态、专注、隐私帘。
3. 第二行负责当前输入：文字或手写、相应工具、素材、内页。
4. 页内负责内容：标题、正文或画布；心情、页签和计划关联折叠进详情。
5. 底栏负责内页顺序：上一组、页序、下一组、续页、书签。

不增加与这五个层级重复的悬浮菜单。工具从纸上移到界面栏，不复制第二套功能节点。

## 组件约束

- 常规工具按钮 34px 高、圆角 5px；不逐个使用浮起的卡片阴影。
- 图标采用现有图标集和 Lucide，重要的图标按钮保留可访问名称及原生提示。
- 文字工具与手写工具互斥显示。较少使用的笔刷参数、清空、全屏收进笔刷设置。
- 弹层圆角最多 8px；可滚动区域在弹层内部，不允许子项探出边界。
- 设置抽屉有背景遮罩、焦点限制、Esc 关闭与焦点返回。
- 保存中、已保存、保存失败是不同状态，文案不截断；失败不能使用成功色。
- 动效只服务于状态和页面转换，用户开启减少动态效果时尊重系统偏好。

## 响应式

- 1100px 以上：侧栏与双页。
- 1100px 及以下：侧栏抽屉与单页切换，避免把双页缩成两条窄纸。
- 600px 及以下：触屏用两行工具区；底栏留出系统安全区。
- 手写逻辑画布统一为 900×1260，各尺寸保持相同比例。旧矢量坐标不缩放；旧位图按自身比例还原。

## 参考边界

- [Goodnotes 界面分组](https://support.goodnotes.com/hc/en-us/articles/13682253498767-Improved-User-Interface)：借鉴导航与编辑工具的职责区分。
- [Craft 导航](https://support.craft.do/en/introduction/navigation)：借鉴集中导航和低干扰编辑。
- [StPageFlip](https://nodlik.github.io/StPageFlip/)：使用已有库的单页/双页支持，不把点击正文绑定为翻页。

这些是交互参考，不是视觉复制。当前是 Web/PWA 界面整理，不代表已完成原生商店审核、健康授权或跨设备同步。
